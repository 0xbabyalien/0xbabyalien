Rivest · 1992 · 128-bit

MD5 — Legenda yang Pensiun

Message Digest 5 pernah menjadi raja checksum. Kini, ia pecah total: collision ditemukan pada 2004, dan membuat file berbeda dengan hash identik hanya butuh detik di laptop biasa.

digest: 32 hex kecepatan: sangat cepat ⚠ status: dilarang
⚠️ Jangan pernah pakai MD5 untuk password atau tanda tangan digital. Kecepatannya justru memudahkan serangan rainbow table & brute-force.
NSA · 1995 · 160-bit

SHA-1 — Jatuh oleh SHAttered

Google & CWI Amsterdam membuktikan collision SHA-1 pada 2017 lewat proyek SHAttered — dua PDF berbeda, satu hash yang sama, biaya hanya ~$110 ribu saat itu.

digest: 40 hex serangan: praktis ✅ status: deprecated
🚫 Git masih memakai SHA-1, tapi dengan pertahanan tambahan. Browser Chrome & Firefox menolak sertifikat SHA-1 sejak 2017.
SHA-2 · NSA · 2001 · 256-bit

SHA-256 — Tulang Punggung Era Ini

Jantung Bitcoin, blockchain, dan TLS modern. Dirancang dari struktur Merkle–Damgård dengan 64 putaran kompresi — belum ada collision yang ditemukan hingga hari ini.

digest: 64 hex ruang: 2²⁵⁶ status: aman ✅
SHA-256("") = e3b0c44298fc1c149afbf4c8996fb924
27ae41e4649b934ca495991b7852b855
NIST · 2015 · Keccak-f[1600]

SHA-3 — Pemenang Kompetisi NIST

Berbasis sponge construction — menyerap input lalu memeras output — arsitektur yang sepenuhnya berbeda dari SHA-2, jadi jika SHA-2 jebol, SHA-3 tetap berdiri.

SHA3-224 / 256 / 384 / 512 SHAKE128: output bebas
💡 SHA-3 dirancang sebagai "asuransi" — diversifikasi matematis agar dunia tidak bergantung pada satu keluarga algoritma.
Aumasson · 2012 · finalis SHA-3

BLAKE2 — Cepat, Aman, Modern

Lebih cepat dari MD5 namun setara keamanan SHA-3. Dipakai oleh Python (hashlib.blake2b), ZFS, dan banyak sistem modern sebagai default checksum.

blake2b: 1–64 byte blake2s: 1–32 byte salt: built-in ✅
🚀 Jika butuh kecepatan tinggi + keamanan nyata, BLAKE2 adalah jawaban terbaik untuk checksum file dan integritas data.
Password Hashing Competition · 2015

bcrypt · scrypt · Argon2

Hash password butuh sengaja lambat dan boros memori — untuk menghukum GPU brute-force. Argon2id adalah juara resmi, pemenang Password Hashing Competition.

bcrypt: cost adaptif scrypt: RAM-hungry Argon2id: juara 🏆
$argon2id$v=19$m=65536,t=3,p=4$[salt]$[hash] → ~64 MB memori, 3 putaran, 4 thread per percobaan.
